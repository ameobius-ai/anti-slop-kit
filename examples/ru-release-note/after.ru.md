# Версия 2.4

В этой версии изменён формат конфигурации. Запросы работают быстрее.

## Перед обновлением

Версия 2.4 не читает файлы конфигурации версии 1. Сначала преобразуйте файл:

```
asdk config migrate config.yaml
```

Команда создаёт файл `config.yaml.v2`. Старый файл остаётся на диске.

## Изменения

- Запросы к таблицам более 1 млн строк выполняются на 40 % быстрее.
- Флаг `--strict` останавливает работу на первой ошибке. Раньше он останавливал работу в конце файла.
- Параметр `legacy_mode` удалён. Вместо него укажите `compat_level: 1`.

## Если обновление не удалось

1. Откройте журнал `/var/log/asdk/update.log`.
2. Найдите первую строку со словом `ERROR`.
3. Отправьте эту строку и файл `config.yaml` на адрес support@example.com.
