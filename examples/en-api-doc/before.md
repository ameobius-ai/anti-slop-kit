# The Jobs API

This comprehensive guide will walk you through everything you need to know about leveraging our powerful and flexible Jobs API in order to orchestrate your workloads seamlessly. Generally speaking, the endpoint can be utilised to facilitate the creation of a job, and it's worth noting that a variety of optional parameters are also available to help you fine-tune the behaviour according to your specific needs. In the event that the request is malformed, an error will be returned by the server, which you may want to handle appropriately in your client code. It is generally recommended that users consider implementing a retry strategy, as transient failures can potentially occur from time to time. Please refer to the extensive documentation below, where we delve into each of the fields in considerable depth.
