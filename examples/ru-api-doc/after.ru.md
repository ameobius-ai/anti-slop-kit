# API задач

## Создайте задачу

```
POST /v1/jobs
```

Отправьте тело запроса в формате JSON. Тело содержит такие поля:

| Поле | Тип | Обязательное | Назначение |
|---|---|---|---|
| `name` | строка | да | Имя задачи в консоли. Не более 64 знаков. |
| `queue` | строка | нет | Очередь задачи. По умолчанию — `default`. |
| `payload` | объект | да | Входные данные задачи. Не более 256 КБ. |

Пример:

```
curl -X POST https://api.example.com/v1/jobs \
  -H 'Authorization: Bearer $TOKEN' \
  -d '{"name": "nightly-export", "payload": {"day": "2026-08-04"}}'
```

## Ответы сервера

| Код | Значение | Что сделать |
|---|---|---|
| 201 | Сервер создал задачу. | Прочитайте идентификатор задачи в поле `id`. |
| 400 | Поле отсутствует или превышает предел. | Исправьте поле, указанное в `error.field`. |
| 429 | Вы отправили более 100 задач за минуту. | Подождите столько секунд, сколько указано в заголовке `Retry-After`. Затем повторите запрос. |
| 503 | Очередь недоступна. | Повторите запрос через 5 секунд. Сделайте не более трёх попыток. |
