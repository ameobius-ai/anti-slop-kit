# Описание работы с API задач

В данном разделе осуществляется рассмотрение вопросов, связанных с реализацией взаимодействия с программным интерфейсом, являющимся ключевым элементом нашей мощной и гибкой платформы. Осуществление процедуры создания задачи производится посредством отправки запроса, содержащего необходимый набор параметров, при этом следует отметить, что часть параметров является опциональной. В целях обеспечения повышения надёжности рекомендуется рассмотреть возможность реализации механизма повторных попыток, поскольку в отдельных случаях могут возникать ошибки, носящие временный характер. В случае, если запрос является некорректным, сервером будет возвращено сообщение об ошибке, обработка которого должна быть предусмотрена на стороне клиента.
