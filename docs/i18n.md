# Internationalization (i18n) Guide

This guide explains how the anti-slop-kit handles multiple languages and how to add new language support.

## Supported Languages

Currently supported languages:
- **English (en)**: Default language
- **Russian (ru)**: Full support

## Language Detection

The tools automatically detect the language of input text using heuristics:
- Character frequency analysis
- Common word patterns
- Language-specific markers

You can also explicitly specify the language using the `--lang` flag:

    python tools/aslint/lint_tool.py --lang en input.md
    python tools/aslint/lint_tool.py --lang ru input.md

## Adding New Language Support

### Step 1: Create Language Pattern File

Create a new pattern file for your language in `tools/aslint/patterns/`:

    tools/aslint/patterns/YOUR_LANG_CODE.yml

Example structure:

    language: your_lang_code
    name: "Language Name"
    
    vague_language:
      - pattern: "very"
        suggestion: "Use more specific adjectives"
      - pattern: "really"
        suggestion: "Remove or replace with specific adverb"
    
    filler_words:
      - pattern: "basically"
        suggestion: "Remove filler word"
      - pattern: "actually"
        suggestion: "Remove unless emphasizing contradiction"
    
    weasel_words:
      - pattern: "some people say"
        suggestion: "Cite specific sources"
      - pattern: "it is said"
        suggestion: "Attribute to specific source"

### Step 2: Update Language Detection

Add your language to the detection logic in `tools/aslint/common.py`:

    def detect_language(text):
        # Add your language detection logic
        if has_cyrillic_chars(text):
            return "ru"
        elif has_your_lang_chars(text):
            return "your_lang_code"
        else:
            return "en"

### Step 3: Test Your Language

Create test files in your language:

    examples/your_lang-test/sample.md

Run the lint tool:

    python tools/aslint/lint_tool.py --lang your_lang_code examples/your_lang-test/sample.md

### Step 4: Update Documentation

Add your language to:
- README.md (supported languages section)
- This i18n guide
- Example directories

## Translation Guidelines

When adding translations:

1. **Keep suggestions actionable**: Explain what to do, not just what's wrong
2. **Be culturally appropriate**: Consider language-specific conventions
3. **Test with native speakers**: Verify suggestions make sense
4. **Maintain consistency**: Use similar tone across all languages
5. **Document edge cases**: Note when patterns don't apply

## Common Patterns Across Languages

Some anti-slop patterns are universal:
- Vague quantifiers ("some", "many", "a lot")
- Filler words (language-specific but conceptually similar)
- Passive voice overuse
- Lack of specific examples

## Testing Multi-Language Support

Run tests for all languages:

    python -m pytest tests/ -k "lang"

Or test specific language:

    python -m pytest tests/ -k "lang_en"
    python -m pytest tests/ -k "lang_ru"

## Contributing Translations

To contribute a new language:

1. Fork the repository
2. Create your language pattern file
3. Add tests for your language
4. Update documentation
5. Submit a pull request

See CONTRIBUTING.md for detailed contribution guidelines.

## Troubleshooting

### Wrong language detected

Explicitly specify language with `--lang` flag:

    python tools/aslint/lint_tool.py --lang en input.md

### Pattern not matching

Check that:
- Pattern is in the correct language file
- Regex syntax is valid
- Pattern is not too specific or too general

### Suggestions not helpful

Update the suggestion text in your language pattern file to be more actionable.
