## Tools Reference

### Lint Tool
Check documents for anti-slop patterns (vague language, filler words, weasel words).

    python tools/aslint/lint_tool.py document.md

### Rewrite Tool
Validate that rewrites improve quality and preserve information.

    python tools/aslint/rewrite_tool.py original.md rewrite.md

### Transmit Check
Verify information fidelity through transformation chains.

    python tools/aslint/transmit_check.py source.md transmitted.md
