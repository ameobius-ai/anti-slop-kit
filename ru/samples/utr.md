# Сервис кэша

Обычный кэш сравнивает запросы по точному тексту. Маленькая правка формулировки даёт промах кэша. Наш сервис сравнивает смысл запроса со смыслом запросов в кэше.

Если два запроса близки по смыслу, сервис вернёт ответ из кэша. Так вы сократите число вызовов модели. Стоимость и время ответа падают.

Чтобы настроить кэш, откройте конфиг и измените три поля. Соблюдайте правила безопасности вашей компании.

Сервер допускает 100 запросов в минуту на один аккаунт. Сверх лимита сервер отклоняет запрос и возвращает ошибку. Посмотрите заголовок Retry-After в ответе. Он показывает точное время ожидания. Подождите это время и повторите запрос.
