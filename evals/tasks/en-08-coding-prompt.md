# Task: Coding Prompt Engineering

Write a system prompt for an AI coding assistant.

Requirements:
1. Deliver complete, working code (no TODOs, no stubs)
2. Use correct APIs and signatures
3. Structure code properly
4. Write useful comments (why, not what)
5. Handle errors robustly
6. Verify code works before presenting

The prompt should be terse, imperative, and specific.

Success criteria:
- Clear completeness requirements
- Specific correctness rules
- Concrete robustness patterns
- Imperative voice throughout
- No hedging language
