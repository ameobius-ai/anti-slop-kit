# Руководство по интеграции с Платежным Шлюзом

Этот документ описывает три основных API эндпоинта для интеграции с нашим платежным шлюзом.

## Создание платежей

Используйте `POST /v1/charges` для создания нового платежа.

**Важно:** Вы можете делать не более 100 запросов в минуту. При превышении лимита получите ошибку 429.

**Обязательные заголовки:**
- `X-API-Key`: Ваш API ключ
- `Idempotency-Key`: Уникальный ключ для предотвращения дублирования платежей
- `Content-Type: application/json`

**Коды ответа:**
- `201`: Платеж создан успешно
- `400`: Неверный запрос (проверьте параметры)
- `402`: Оплата не прошла (например, недостаточно средств)
- `429`: Превышен лимит запросов (подождите и повторите)

## Получение информации о платеже

Используйте `GET /v1/charges/{id}` для получения деталей существующего платежа.

**Лимит:** 500 запросов в минуту.

**Обязательные заголовки:**
- `X-API-Key`: Ваш API ключ

**Коды ответа:**
- `200`: Платеж найден
- `404`: Платеж не найден (проверьте ID)

## Создание возвратов

Используйте `POST /v1/refunds` для возврата предыдущего платежа.

**Важно:** Вы можете делать не более 50 запросов в минуту.

**Обязательные заголовки:**
- `X-API-Key`: Ваш API ключ
- `Idempotency-Key`: Уникальный ключ для предотвращения дублирования возвратов

**Коды ответа:**
- `201`: Возврат создан успешно
- `400`: Неверный запрос
