Напишите системный промпт для ИИ-агента, который ревьюит pull request'ы на
качество кода. Агент должен проверять типовые проблемы: TODO-заглушки, типовые
имена переменных, отсутствие обработки ошибок и слабые тесты. Промпт задаёт
роль агента, критерии оценки, формат вывода и тон. Он должен быть достаточно
конкретным, чтобы два прогона на одном и том же PR давали согласованный ответ.

Системный промпт пойдёт в код-ревью бота в CI/CD пайплайне. Бот получает диффы
PR и возвращает структурированный ответ с номерами строк и конкретными
правками.
