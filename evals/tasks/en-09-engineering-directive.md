# Task: Engineering Directive Writing

Write an engineering directive covering:

1. Scope adherence
2. Interpreting requirements
3. Response structure
4. Completeness
5. Correctness
6. Buildability
7. Code structure
8. Comments
9. Robustness
10. Verification

The directive should be terse and imperative.

Success criteria:
- Covers all 10 areas
- Each section has specific rules
- Includes anti-patterns
- Consistent formatting
- No filler words
