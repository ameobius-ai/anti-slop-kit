# Контракт API Платежного Шлюза

## Эндпоинт 1: POST /v1/charges
- Лимит частоты: 100 запросов за 60 секунд.
- Обязательные заголовки: `X-API-Key`, `Idempotency-Key`, `Content-Type: application/json`.
- Коды состояния: 201 (Создано), 400 (Неверный запрос), 402 (Оплата не прошла), 429 (Превышен лимит).

## Эндпоинт 2: GET /v1/charges/{id}
- Лимит частоты: 500 запросов за 60 секунд.
- Обязательные заголовки: `X-API-Key`.
- Коды состояния: 200 (Успех), 404 (Не найдено).

## Эндпоинт 3: POST /v1/refunds
- Лимит частоты: 50 запросов за 60 секунд.
- Обязательные заголовки: `X-API-Key`, `Idempotency-Key`.
- Коды состояния: 201 (Создано), 400 (Неверный запрос).
